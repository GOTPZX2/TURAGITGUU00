# วิธีแก้บัคสมัครสมาชิกไม่ได้ + เชื่อมต่อฐานข้อมูล Neon + AI ค้นหา + การแจ้งเตือน

## อัปเดตล่าสุด: การแจ้งเตือน + แปลภาษาหน้าประวัติ + หมวดหมู่แจ้งเตือนใหม่

**1) แจ้งเตือนไม่ขึ้นบนมือถือ (แก้แล้ว)**
โค้ดเดิมเรียก `new Notification(...)` ตรง ๆ ซึ่งบนเบราว์เซอร์มือถือหลายตัว (เช่น Chrome
บน Android) จะโยน error ทันทีเพราะเบราว์เซอร์กลุ่มนี้บังคับให้แจ้งเตือนต้องมาจาก
Service Worker เท่านั้น (`ServiceWorkerRegistration.showNotification()`) — เดิม error
ถูกจับเงียบ ๆ ด้วย try/catch เลยดูเหมือนแอปไม่มี error แต่แจ้งเตือนก็ไม่เคยขึ้นบนมือถือ
เพิ่มไฟล์ `sw.js` (Service Worker ตัวเล็ก ๆ ไม่มี cache/offline logic) และเปลี่ยนทุกจุดที่
เคยเรียก `new Notification()` ตรง ๆ ให้เรียกผ่าน Service Worker ก่อน แล้วค่อย fallback
ไปที่ `new Notification()` ถ้าเบราว์เซอร์ไม่รองรับ SW เลย — ใช้งานได้ทั้งเดสก์ท็อปและมือถือ

**2) หน้า "ประวัติ" ไม่แปลภาษา (แก้แล้ว)**
คำแปลของเมนู/หน้า "ประวัติ" (nav_history, historyTitle, searchHistory ฯลฯ) มีอยู่แค่ใน
พจนานุกรมภาษาไทยเท่านั้น ไม่มีในอังกฤษ/ฟินแลนด์เลย เวลาเปลี่ยนแอปเป็นอังกฤษหรือฟินแลนด์
ระบบเลย fallback กลับไปโชว์เป็นไทยเสมอ — เพิ่มคำแปลครบทั้ง EN/FI แล้ว
นอกจากนี้ "ประวัติการบันทึกทั้งหมด" (activity log เช่น "บันทึกรายการธุรกรรม") เดิมเก็บ
เป็นข้อความไทยตายตัวลงฐานข้อมูล ไม่เปลี่ยนตามภาษาแอปเลย — แก้ให้เก็บเป็น "รหัสคำแปล"
แทน แล้วแปลตอนแสดงผลตามภาษาที่เลือกอยู่ ณ ขณะนั้น (รายการเก่าที่เคยบันทึกไว้ก่อนอัปเดตนี้
จะยังโชว์เป็นข้อความเดิมที่เคยบันทึกไว้ เพราะข้อความเก่าไม่มี "รหัส" ให้แปลย้อนหลังได้)

**3) หมวดหมู่การแจ้งเตือนใหม่: "บันทึกของวันนี้"**
เพิ่มหมวดหมู่ที่ 3 ในกระดิ่งแจ้งเตือน/แจ้งเตือนอุปกรณ์ ต่อจาก "ภารกิจ/นัดหมายวันนี้" และ
"คาบเรียนวันนี้" — ถ้ามีบันทึก (หน้า "บันทึก") ที่ตั้งวันที่ตรงกับวันนี้ ระบบจะเด้งแจ้งเตือน
1 ครั้งต่อวันต่อบันทึก และแสดงในกระดิ่งแจ้งเตือนด้วย มีคำแปลครบทั้ง 3 ภาษา (ไทย/อังกฤษ/ฟินแลนด์)
เหมือนหมวดหมู่เดิม ใช้การตั้งค่า "แจ้งเตือนล่วงหน้า" ชุดเดียวกับหมวดอื่นในหน้าตั้งค่า



## ฟีเจอร์ค้นหาด้วย AI (ปุ่ม TURAGITGUU AI)

ปุ่มค้นหา AI ยิงคำถามไปที่ **Groq และ Mistral พร้อมกัน** (ผ่านไฟล์ `api/ai.js` ที่ proxy
คำขอฝั่งเซิร์ฟเวอร์ ไม่มี API key หลุดไปที่เบราว์เซอร์) ทั้งสองเจ้าตอบคำถามเดียวกันแยกกัน
จากนั้นให้ Groq อีกครั้งช่วย **สรุป/รวมคำตอบทั้งสองเป็นคำตอบเดียว** ที่กระชับ ไม่ซ้ำซ้อน
และไม่ขัดแย้งกันเอง ก่อนแสดงผลในหน้าเว็บ ถ้าเจ้าใดเจ้าหนึ่งพลาด (โควตาหมด/ยังไม่ได้ตั้ง key)
ระบบจะใช้คำตอบจากอีกเจ้าแทนโดยอัตโนมัติ

**ข้อควรรู้**: Groq และ Mistral ไม่มีความสามารถค้นเว็บแบบเรียลไทม์ในตัว (ต่างจาก Gemini)
คำตอบจึงมาจากความรู้ที่โมเดลมีอยู่แล้ว เหมาะกับคำถามทั่วไป/ส่วนตัว (การเงิน บันทึก ตาราง
เรียนในแอป) แต่ถ้าถามเรื่องข่าวหรือข้อมูลที่เปลี่ยนเร็วมาก ๆ คำตอบอาจไม่ใช่ข้อมูลล่าสุด

ต้องเพิ่มตัวแปรแวดล้อมบน Vercel (ขั้นตอนเดียวกับ `DATABASE_URL` ด้านล่าง) อย่างน้อย 1 ใน
2 ตัวนี้ (แนะนำให้ใส่ทั้งคู่เพื่อให้มีการสรุปสองมุมมอง):

- Name: `GROQ_API_KEY`
  Value: API key จาก https://console.groq.com/keys (สมัครฟรีด้วยอีเมล ไม่ต้องผูกบัตร)
- Name: `MISTRAL_API_KEY`
  Value: API key จาก https://console.mistral.ai (สมัครฟรี เลือกแพ็กเกจ La Plateforme
  free/Experiment tier ไม่ต้องผูกบัตรสำหรับโควตาฟรี)

ถ้าไม่ตั้งค่าตัวใดเลย ฟีเจอร์ AI จะขึ้น error แต่ระบบสมัครสมาชิก/ล็อกอิน/บันทึกข้อมูล
(ที่ใช้ `DATABASE_URL`) จะไม่เกี่ยวข้องกันและทำงานได้ตามปกติ

## สาเหตุของบัคสมัครสมาชิก

ปุ่ม "สมัครสมาชิก" เรียก `/api/auth` (ไฟล์ `api/auth.js`) ซึ่งต้องคุยกับฐานข้อมูล
Postgres ผ่านตัวแปรแวดล้อม `DATABASE_URL` — ตอนนี้ยังไม่มีฐานข้อมูลจริงเชื่อมต่ออยู่
เวลาเรียก API แล้วพัง (เช่น เปิด `index.html` ตรง ๆ โดยไม่มีเซิร์ฟเวอร์ หรือ deploy
แล้วแต่ยังไม่ได้ตั้ง `DATABASE_URL`) หน้าเว็บจะจับ error ทุกแบบแล้วโชว์ข้อความ
"กรุณากรอกข้อมูลให้ครบทั้งสองช่อง" เหมือนกันหมด ทั้งที่จริง ๆ กรอกข้อมูลครบแล้ว —
นี่คือบัคที่เจอ ผมแก้ในไฟล์ `index.html` แล้วให้แสดงข้อความที่ตรงกับปัญหาจริง
(เช่น "เชื่อมต่อระบบไม่ได้ กรุณาลองใหม่ภายหลัง" เมื่อเป็นปัญหาฝั่งเซิร์ฟเวอร์/ฐานข้อมูล)

โค้ดฝั่ง backend (`api/auth.js`, `api/data.js`, `lib/db.js`) ที่คุณอัปโหลดมาถูกต้องอยู่แล้ว
และเขียนมาให้ใช้ `@neondatabase/serverless` — **ผมไม่มีสิทธิ์เข้าถึงอินเทอร์เน็ตจากในนี้
จึงไม่สามารถไปสมัคร/สร้างฐานข้อมูล Neon จริงแทนคุณได้** ต้องทำตามขั้นตอนด้านล่างเอง
(ใช้เวลาไม่เกิน 5 นาที ฟรี ไม่ต้องผูกบัตร)

## ขั้นตอนตั้งค่า Neon

1. ไปที่ https://neon.tech แล้วสมัคร/ล็อกอิน (ใช้ GitHub ล็อกอินได้เลย)
2. กด **Create a project** ตั้งชื่ออะไรก็ได้ เช่น `TURAGITGUU`
3. หลังสร้างเสร็จ Neon จะโชว์ **Connection string** หน้าตาประมาณ
   `postgresql://USER:PASSWORD@HOST/neondb?sslmode=require`
   — กดคัดลอกเก็บไว้ (นี่คือค่า `DATABASE_URL`)
4. ไปที่แท็บ **SQL Editor** ในหน้า Neon แล้ววางเนื้อหาทั้งหมดจากไฟล์ `schema.sql`
   ที่แนบมาให้ แล้วกด Run — จะได้ตาราง `accounts` กับ `kv_store` ตามที่โค้ด
   `api/auth.js` และ `api/data.js` ต้องใช้

## ขั้นตอนตั้งค่าบน Vercel

1. อัปโหลดโฟลเดอร์นี้ (หรือ push ขึ้น GitHub แล้ว import) เข้า Vercel เป็นโปรเจกต์ใหม่
2. ในหน้า **Project → Settings → Environment Variables** เพิ่มตัวแปร:
   - Name: `DATABASE_URL`
   - Value: connection string จาก Neon ที่คัดลอกไว้ในขั้นตอนก่อนหน้า
   - เลือกให้ใช้ได้ทั้ง Production/Preview/Development
   - แล้วเพิ่มอีก 1-2 ตัวแปร: `GROQ_API_KEY` และ/หรือ `MISTRAL_API_KEY` (ดูวิธีขอ key
     ในหัวข้อด้านบน) ถ้าต้องการให้ฟีเจอร์ AI ค้นหาทำงานได้ด้วย
3. Deploy (หรือ Redeploy ถ้า deploy ไปแล้ว) — Vercel จะรัน `npm install` ให้เอง
   เพื่อดึงแพ็กเกจ `@neondatabase/serverless` ตาม `package.json`
4. ทดสอบสมัครสมาชิกใหม่บนเว็บที่ deploy แล้ว ควรใช้งานได้ปกติ

## หมายเหตุ

- ถ้าคุณแค่เปิด `index.html` เป็นไฟล์เฉย ๆ ในเบราว์เซอร์ (ไม่ได้ผ่าน Vercel/เซิร์ฟเวอร์)
  ระบบสมัคร/ล็อกอินจะใช้งานไม่ได้เสมอ เพราะไม่มี `/api/auth` ให้เรียก — ต้อง deploy
  ขึ้น Vercel (หรือรันด้วย `vercel dev` ในเครื่องที่มี Node.js) เท่านั้น
- รหัสผ่านถูก hash ด้วย scrypt ก่อนเก็บลงฐานข้อมูลอยู่แล้ว (ดูใน `lib/password.js`)
  ปลอดภัยในระดับที่เหมาะสม ไม่ต้องแก้อะไรเพิ่ม

## อัปเดตล่าสุด: แดชบอร์ดกดดูข้อมูลได้ + คัสตอมสี/ฟอนต์/ความหนาบาง + วอลเปเปอร์ 3D + แจ้งเตือนพุชจริง

**1) แดชบอร์ดกดเข้าไปดูข้อมูลได้จริง**
การ์ดในหน้าแดชบอร์ดตอนนี้กดได้แล้ว: วงกลม "งานวันนี้" กดเปิดรายการของวันนี้, การ์ด
"ยอดคงเหลือ" กดไปหน้าการเงิน, แท่งกราฟ "รายจ่าย 7 วัน" กดดูรายจ่ายของวันนั้นเป็นลิสต์,
วงกลมโดนัท "สัดส่วนรายจ่าย" กดแต่ละหมวดดูธุรกรรมในหมวดนั้น, "งานค้าง" กดดูลิสต์ทั้งหมด,
"บันทึกทั้งหมด/วิชาทั้งหมด" กดไปหน้านั้น ๆ, และ "บันทึกล่าสุด" กดเปิดบันทึกนั้นได้เลย

**2) ปรับสี ฟอนต์ และความหนา-บางของ UI ได้ (หน้าตั้งค่า)**
เพิ่มการ์ดใหม่ 2 การ์ดในหน้าตั้งค่า:
- **ฟอนต์และความหนา-บาง**: เลือกฟอนต์ไทยได้ 6 แบบ (Anuphan, Kanit, Prompt, Mitr, Sarabun,
  IBM Plex Sans Thai) และสไลเดอร์ปรับ "ความหนา-บาง" ของ UI ทั้งแอปในค่าเดียว
  (น้ำหนักตัวอักษร + ความมนของมุมการ์ด/ปุ่ม + ความหนาเส้นขอบ)
- สีธีม (accent) และสีพื้นหลัง (void) ใช้ระบบเดิมที่มีอยู่แล้ว

**3) วอลเปเปอร์เคลื่อนไหวแบบ 3D ปรับได้**
การ์ด "วอลเปเปอร์" มี 3 โหมดให้เลือก: ไม่ใช้ / รูปภาพ (แบบเดิม) / **เคลื่อนไหว 3D** — โหมดใหม่
เป็นก้อนแสงสีลอยไปมาแบบ blur เคลื่อนที่ 3 มิติตามการเอียงมือถือ (ต้องกดปุ่ม "เปิดเซนเซอร์เอียง
มือถือ" หนึ่งครั้งก่อน เพราะ iOS บังคับให้ต้องขอสิทธิ์จากการแตะของผู้ใช้) หรือขยับตามเมาส์บน
เดสก์ท็อป ปรับ "ความลึก 3D" และ "ความเร็วการเคลื่อนไหว" ได้อิสระ

**4) แจ้งเตือนแบบพุชจริง ใช้งานได้แม้ปิดแอป/ปิดเบราว์เซอร์**
ระบบแจ้งเตือนเดิม (ใน STATE.settings.notifications) ทำงานได้แค่ตอนเปิดแท็บเว็บนี้ค้างไว้
เท่านั้น เพราะเช็คด้วย `setInterval` ฝั่งเบราว์เซอร์ — พอปิดแท็บ/ปิดแอปแล้วแจ้งเตือนก็หยุดทันที
รอบนี้เพิ่มระบบ **Web Push จริง** ที่ทำงานฝั่งเซิร์ฟเวอร์แทน:

- หน้าตั้งค่า → การ์ดแจ้งเตือน มีปุ่มใหม่ "เปิดใช้งานแจ้งเตือนพุช" กดครั้งเดียวเพื่อขอสิทธิ์
  และลงทะเบียนอุปกรณ์
- ไฟล์ใหม่ `api/push.js` เก็บ/ลบข้อมูลการลงทะเบียนอุปกรณ์ (push subscription) ต่อผู้ใช้
  ลงตาราง `push_subscriptions` (เพิ่มใน `schema.sql` แล้ว — **ต้องรัน SQL ใหม่นี้ในขั้นตอน
  Neon SQL Editor ด้วย ถ้าคุณตั้งฐานข้อมูลไปแล้วก่อนหน้านี้**)
- ไฟล์ใหม่ `api/send-reminders.js` ทำงานตามตารางเวลา (cron, ตั้งไว้ใน `vercel.json` ทุก 15
  นาที) เช็คงาน/นัดหมาย/คาบเรียน/บันทึกที่ใกล้ถึงเวลาของทุกผู้ใช้ที่เปิดพุชไว้ แล้วยิงแจ้งเตือน
  จริงผ่าน `web-push` ไปที่โทรศัพท์ แม้ไม่ได้เปิดเว็บไซต์ค้างไว้เลยก็ตาม
- `sw.js` เพิ่ม event listener `push` เพื่อรับและแสดงแจ้งเตือนที่ส่งมาจากเซิร์ฟเวอร์
- เพิ่ม `manifest.json` + ไอคอนแอป ให้สามารถ "เพิ่มลงหน้าจอโฮม" (Add to Home Screen) ได้
  ซึ่ง**จำเป็นมากสำหรับ iPhone** — Safari บน iOS จะไม่ส่งแจ้งเตือนพุชให้เลยถ้าไม่ได้ติดตั้ง
  เว็บเป็นแอปจากหน้าจอโฮมก่อน (เมนู แชร์ → เพิ่มไปยังหน้าจอโฮม)

     `/api/send-reminders` เล่นได้
   - คู่ค่า VAPID ด้านบนผมสร้างให้จริงแล้ว (ใช้งานได้เลย ไม่ต้องสร้างเอง) แต่ถ้าอยากสร้างคู่ใหม่
     เอง รันคำสั่ง `npx web-push generate-vapid-keys` ในเครื่องที่มี Node.js — ถ้าสร้างใหม่
     อย่าลืมแก้ค่า `VAPID_PUBLIC_KEY` ในไฟล์ `index.html` (ค้นหาตัวแปร `VAPID_PUBLIC_KEY`)
     ให้ตรงกับคู่ใหม่ด้วย ไม่งั้นแอปกับเซิร์ฟเวอร์จะใช้กุญแจคนละคู่กัน พุชจะไม่ทำงาน
3. **Deploy/Redeploy** — Vercel จะรัน `npm install` ดึงแพ็กเกจ `web-push` ให้อัตโนมัติตาม
   `package.json`
4. **เกี่ยวกับตารางเวลา cron**: `vercel.json` ตั้งให้รัน `/api/send-reminders` ทุก 15 นาที
   แต่แผน **Vercel Hobby (ฟรี) จำกัดความถี่ของ Cron Jobs** (แผนฟรีบางช่วงอนุญาตแค่วันละครั้ง
   ขึ้นอยู่กับนโยบายปัจจุบันของ Vercel ตอนที่คุณ deploy) ถ้า cron ในตัวไม่ทำงานถี่พอ ให้ใช้
   บริการฟรีภายนอกแทน เช่น https://cron-job.org สร้างงานให้ยิง URL
   `https://โดเมนของคุณ.vercel.app/api/send-reminders?secret=ค่าCRON_SECRETที่ตั้งไว้`
   ทุก 5–15 นาทีแทนได้เลย ผลลัพธ์เหมือนกัน
5. ทดสอบ: เข้าเว็บ (แนะนำให้ "เพิ่มไปยังหน้าจอโฮม" ก่อนถ้าเป็น iPhone) → ตั้งค่า → เปิด
   "แจ้งเตือน" (สวิตช์เดิม) และกด "เปิดใช้งานแจ้งเตือนพุช" → ตั้งงาน/นัดหมายให้ถึงเวลาภายใน
   ไม่กี่นาที → ปิดแอป/ปิดเบราว์เซอร์แล้วรอ ควรมีแจ้งเตือนขึ้นที่มือถือแม้แอปปิดอยู่

**หมายเหตุเรื่องเขตเวลา**: ระบบเก็บ timezone ของอุปกรณ์ตอนกดเปิดพุช (เช่น `Asia/Bangkok`)
ไว้คำนวณเวลาแจ้งเตือนฝั่งเซิร์ฟเวอร์ให้ตรงกับเวลาท้องถิ่นของคุณ ถ้าเปลี่ยนเขตเวลาอุปกรณ์
ทีหลัง ให้กดปุ่ม "เปิดใช้งานแจ้งเตือนพุช" ซ้ำอีกครั้งเพื่ออัปเดตค่า
